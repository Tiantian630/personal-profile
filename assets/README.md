# 素材文件夹说明

- `zno/`：海外 SEO 案例素材。Blog 依次使用 `blog-destination-wedding.webp`、`blog-pixellu-alternatives.webp`、`blog-video-download.webp`、`blog-event-photo-sharing.webp`；内容资产使用 `photography-startup-checklist.webp`；社媒视频封面使用 `video-event-content-cover.webp`、`video-product-demo-cover.webp`
- `foxdata/`：ASO 指南与公众号文章截图
- `pet/`：宠物电商短视频、UGC 内容截图
- `bookuu/`：微博截图、周年庆视频封面
- `ai/`：AI 漫剧封面、角色、分镜、场景和最终画面
- `booking/`：日租预约系统截图，使用 `booking-home.webp`、`booking-form.webp`、`booking-admin.webp`
- `kitchen/`：甜甜私房菜截图，使用 `kitchen-home.webp`、`kitchen-recipes.webp`、`kitchen-shopping.webp`

建议使用 `.webp`，并保持单张文件足够轻量。素材放入对应目录后会自动显示；未放入时页面会保留占位提示。
